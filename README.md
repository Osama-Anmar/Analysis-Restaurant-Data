# Analysis-Restaurant-Data
This repository contains the analysis of restaurant sales data to understand trends, patterns, and insights that can drive business decisions.
 
 # Data
 https://github.com/Ernest-30/Restaurant-Sales-Analysis

# Project Overview
The goal of this project is to analyze restaurant sales data to identify key insights such as peak sales periods, delivery rating, food rating, and customer purchasing behavior. The analysis will assist in making informed decisions to optimize sales and improve customer satisfaction.

# Usage
```bash
git clone https://github.com/Osama-Anmar/Analysis-Restaurant-Data.git
cd Analysis-Restaurant-Data
pip install -r requirements.txt
jupyter notebook "Restaurant Sales.ipynb"
```
